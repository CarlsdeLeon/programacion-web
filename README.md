# Django Project with Docker

## Description
This is a Django project that runs with Docker and Docker Compose.  
It includes a web app and a PostgreSQL database.

## Requirements
Before starting, make sure you have installed:

- Docker  
- Docker Compose  

You can check with:

docker --version
docker compose version

## How to Run
To build and run the project, open the terminal and use:
docker compose up --build

When everything is ready, open this link in your browser:
http://localhost:8000

## How to Stop
docker compose down
